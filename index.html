library

Companion apps for the courses. Each one is a single self contained page: nothing is installed, nothing is sent anywhere, and every figure is computed live in the browser so a slider or a click changes the mathematics rather than the picture.

To add a topic, open this file and add one entry to the LECTURES array at the top of the script. Set href to the new page and status to "ready" once it exists, or leave it as "planned" to show it as a placeholder.
