Part 01

The vocabulary, one object at a time

The core vocabulary: graph, vertex, edge, edge set, neighbour, degree, average degree, walk, path, cycle, connectivity, eccentricity, radius and centre. Then two ways of saying that two graphs are the same, and what an invariant is for.

Formal definitions

Graph. G = (V, E) where V is a finite set of vertices and E a set of edges. An undirected edge is an unordered pair {u, v}.

Neighbour. N(v) = { u : {u,v} ∈ E }. Two vertices joined by an edge are adjacent.

Degree. deg(v) = |N(v)|, the number of edge ends at v.

Walk, path, cycle. A walk is a sequence of vertices with each consecutive pair adjacent. A path is a walk with no repeated vertex. A cycle is a walk that returns to its start and repeats nothing else.

Connectivity. G is connected when a path exists between every pair of vertices. Otherwise it splits into connected components.

Handshake lemma and average degree
Σv∈V deg(v) = 2|E|. Each edge is counted once at each of its two ends, so the degree sum is always even. Dividing by |V| gives the average degree d(G) = 2|E|/|V|, the single number that says how dense a graph is: d(G) near 2 means a sparse network, close to |V| - 1 means nearly complete.

Part 03

Notions built on the families

A root turns a tree into an order. A spanning tree turns a network into a skeleton. An embedding turns a graph into a picture with faces. These are the working notions the algorithms later depend on.

    Disconnected graphs
    
        Both procedures only reach the component containing the start vertex. To cover the whole graph, wrap them in a loop over all vertices and restart at any vertex still unvisited. The number of restarts is the number of connected components. Try the two components preset above.
      
    
      
    
        
    What comes next
    
        Every algorithm in Part 2 is one of these two traversals with a twist: Dijkstra is BFS with a priority queue, topological sort is DFS reading its finishing order, max flow is BFS run again and again on a changing graph.
