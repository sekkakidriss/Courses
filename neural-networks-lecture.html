Part 01

What a network actually is

Start with one

A single neuron

A neuron does three things and nothing more: multiply each input by a weight, add them up with a bias, then pass the total through one fixed nonlinear function. Move the sliders and watch the two stages separately.

The whole neuron
z = w₁x₁ + w₂x₂ + w₃x₃ + b then a = f(z). The weights say how much each input matters and in which direction, the bias shifts the threshold, and f supplies the only nonlinearity in the entire model. A network is thousands of these, arranged in layers, and the weights and biases are the parameters that training changes.

Shapes are the whole trick

z₁ = W₁x + b₁ with W₁ of shape (hidden, inputs) and x of shape (inputs, 1), giving z₁ of shape (hidden, 1).

a₁ = f(z₁), applied element by element.

z₂ = W₂a₁ + b₂, shape (outputs, 1).

p = softmax(z₂), shape (outputs, 1), summing to 1.

Part 04

Argmax and softmax

The last layer produces three unbounded numbers. Turning them into an answer is easy. Turning them into an answer you can learn from is the reason softmax exists.

Move the three scores
Argmax against softmax
argmaxsoftmax
Outputone indexa probability for every class
Rangea labeleach in (0,1), summing to 1
Derivativezero everywhere, undefined at tiessmooth everywhere
Can you learn from itno, the gradient carries no informationyes, this is the entire point

Note that softmax is shift invariant: adding the same constant to every score leaves the probabilities unchanged. Implementations subtract the largest score before exponentiating, which prevents overflow and changes nothing.

Part 05

Cross entropy, the cost of being confidently wrong

Once the network outputs probabilities, the loss only looks at one of them: the probability it assigned to the class that was actually true.

Why this shape

L = -ln(ptrue). At p = 1 the loss is 0. As p falls toward 0 the loss rises without bound, so being confident and wrong is punished far harder than being uncertain.

With one hot targets the general formula L = -Σk yk ln(pk) collapses to that single term, because every other yk is zero. Squared error also has its minimum in the right place but its gradient goes flat exactly where the model is most wrong, which is why classification uses cross entropy.

Part 06

The chain rule, the only calculus you need

A network is functions inside functions. The chain rule says the derivative of the whole is the product of the local derivatives, which is what makes a deep model differentiable at all.

A three link chain
Read it as a message passing backwards

dL/dx = (dL/dc)(dc/db)(db/dx). Each factor is local: it needs only its own inputs and outputs, not the rest of the network. That locality is the reason backpropagation can be implemented once, per layer type, and then composed arbitrarily.

The numeric check above compares the analytic product against a finite difference, (L(x+h) - L(x-h)) / 2h. Any framework you write should pass this test before you trust it.

Part 07

The softmax derivative, the cross entropy derivative, and the simplification

Two messy derivatives that multiply into something startlingly clean. This is the single most useful piece of algebra in classification.

Messy on its own

The softmax Jacobian

Softmax takes a vector to a vector, so its derivative is a matrix. Every output depends on every input, because the denominator contains all of them. Two cases:

∂pi / ∂zj = pi(1 - pi) when i = j

∂pi / ∂zj = -pipj when i ≠ j

Computed from the current probabilities

Each row sums to zero: pushing one score up must pull the others down, since the probabilities always sum to one.

Clean when combined

Cross entropy derivative

∂L / ∂ptrue = -1 / ptrue, which explodes as the model gets it badly wrong. Multiply that by the Jacobian above and almost everything cancels:

The result worth memorising
∂L / ∂z = p - y. Predicted probabilities minus the one hot target. That is the error signal that starts the backward pass, and it is why softmax and cross entropy are always implemented as a single fused operation rather than two.
Part 08

Gradient descent, and why all parameters move together

The gradient is a vector with one component per parameter. Every component is computed from the same forward pass, and every parameter is updated in the same step.

One parameter first

Rolling downhill

The update rule
w ← w - η ∂L/∂w. The derivative gives the direction of steepest increase, so the minus sign walks downhill, and η decides how far. Too small and you crawl, too large and you overshoot the valley and climb the far wall. Push the slider past about 1.0 and watch it diverge.
Now two at once

Simultaneous updates

With two parameters the loss is a surface and the gradient has two components. The tempting mistake is to update one parameter, recompute, then update the other. Gradient descent does not do that: both components are computed from the same point, then both parameters move together.

In vector form
θ ← θ - η ∇L(θ) where θ holds every weight and bias in the network stacked into one vector. For the small network in this lecture that is numbers moving in one step. The alternating version above still reaches a minimum here, but it takes a zigzag path, and on a network with millions of parameters it would need millions of forward passes per update instead of one.
